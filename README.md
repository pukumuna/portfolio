# Portfolio GSK

Application React + Vite + React Router, responsive, avec bases SEO et accessibilité.

## Lancer le projet

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## À personnaliser
- Remplacer le logo provisoire dans la zone portrait par votre photo.
- Ajouter e-mail, LinkedIn et GitHub.
- Ajouter captures/mockups, URL GitHub et démos live aux fiches projets.
- Ajuster les textes et résultats aux livrables définitifs.
